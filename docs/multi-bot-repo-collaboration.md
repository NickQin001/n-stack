# 多 bot 协作约定

Nick 跨仓库与 bot 协作时按下面做。各 bot 遵守 [共享前置原则](../principles/shared-preamble.md)。

## 分工

1. **Nick_001** 是日常入口，负责排期、跨仓库协调和普通请求。
2. 专职 bot（例如资料核验员、GitHub 管理员）按需要加入同一个项目仓库。多个 bot 可以一起做一个项目。
3. 按 GitHub 仓库里的文件组织工作，不为每个项目单独建一个 bot。
4. 跨仓库共用的约定放在本仓库 `n-stack`。每个项目仓库自己记进度、术语和决策。

## 项目仓库建议布局

这是约定，不是必须执行的脚手架。

- `docs/status.md` — 当前进度
- `docs/glossary.md` — 稳定术语
- `docs/decisions/` — 过去为什么这样选

聊天是工作台。要长期保留的状态写进仓库。
